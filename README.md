## 🎯 About ZenBonsai

**ZenBonsai** is a modern, elegant web application dedicated to the art of bonsai. It provides a beautiful and seamless user experience for enthusiasts to explore, learn about, and purchase bonsai trees.

> 🌟 *"Cultivate patience, mindfulness, and a deeper connection with nature."*

### ✨ Why Choose ZenBonsai?

- 🎨 **Beautiful UI/UX** - Crafted with attention to detail using modern design principles.
- 🚀 **Lightning Fast** - Built on Vite for optimal performance.
- 📱 **Fully Responsive** - Perfect experience across all devices.
- 🛍️ **Simple & Elegant** - A clean and focused user experience.

## 🚀 Installation

### Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v18 or higher) - [Download](https://nodejs.org/)
- **npm** (comes with Node.js)
- **Git** - [Download](https://git-scm.com/)

### Step 1: Clone the Repository

```bash
git clone https://github.com/panduthegang/Bonsai-Saas.git
cd Bonsai-Saas
```

### Step 2: Install Dependencies

```bash
npm install
```

### Step 3: Run Development Server

```bash
npm run dev
```

The application will open at `http://localhost:5173` 🎉

### Step 4: Build for Production

```bash
npm run build
```

### Step 5: Preview Production Build

```bash
npm run preview
```
